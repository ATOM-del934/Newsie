# 每周新增一期 · 操作步骤

## 排版规格（第 1 期定稿，后续各期沿用）

第 1 期已确定为**报纸头版式**，后续每期按同一套规格生成：

| 项 | 规格 |
|:--|:--|
| 主题 | 浅色暖白纸面 `#fbfaf7` / `#fdfcf9`，衬线做标题与正文 |
| 报头 | 刊名「一周速览」+ 竖排 GLOBAL WEEKLY + 右侧期号日期，下方三线双规 |
| 头条区 | 左主稿（双栏正文）+ 右「关键数字」方框 |
| 正文 | 4 栏网格；**等宽且无表格的行用 `columns` 多栏流** |
| **短报道分块** | 多栏流里每条报道包成 `.ritem`，`break-inside:avoid` **整条不跨栏**，条目间加细分隔线 |
| 分区标签 | `.sect` **16px** 实底色块 + 该分区**3px 通栏主色顶线**，分区之间 26px 间距 |
| 事件标题 | `h3` **19px / 800**；深度信号标题 20px |
| 数字对齐 | 数值 `white-space:nowrap` + `align-items:baseline` + `tabular-nums` |
| 重点标注 | `.key`（红字）/ `.keyu`（红色下划线），**全篇只标 8–12 处**，不要每条都标 |
| 导航 | 单行 sticky，各项之间 1px 细竖线 |
| 主色 | 诺奖 `#8a5a00` / 地缘 `#1d4ed8` / 经济 `#b91c1c` / AI `#6d28d9` / 科学 `#047857` / 社会 `#c2410c` / 文体 `#a21caf` / 深度信号 `#1f4d3a` |
| 重点色 | `#e11d48`（要比对各分区主色，确保能分辨） |

**硬性约束**（第 1 期踩过坑，务必守住）：

1. **全文零 em-dash（U+2014）** —— **包括 CSS/HTML 注释里的**。我在注释里犯过两次。
2. 不要装饰性分区编号（`01 / 02` 之类）；深度信号的 01–09 是内容，允许。
3. 不要纯黑投影（`rgba(0,0,0,…)`），用 `rgba(18,20,15,…)`。
4. 单文件、零外部依赖：`<script>` / `<link>` / `<img>` / `@import` / `url(` 全为 0。
5. 首字下沉只用 `>` 精确定位到正文首段；**不要给数字开头的段落做首字下沉**
   （`10 年期美债…` 会被拆成巨大的 `1` + `0`）。
6. **不要用正则改结构复杂的 HTML** —— 坏过两次，用浏览器的真实 DOM 重组。

## 操作步骤

1. 把这一期的速览 HTML 放进本目录 `issues/`，命名建议 `全球一周速览-YYYY-MM-DD_DD.html`
2. 打开上一层的 `index.html`，在 `ISSUES` 数组的**最前面**插入一条新记录：

```js
{
  id: '2026-10-11_17',                        // 唯一 id，建议用起止日期
  range: '2026.10.11 – 10.17',                // 覆盖区间（跨年区间请写全第二个年份）
  file: 'issues/全球一周速览-2026-10-11_17.html',
  size: '72 KB',
  kicker: '第 2 期',
  msg: '一句话概括这周……可以用 <span class="hl">高亮</span> 标重点。',
  errataIntro: '对上一期的复核结果。',
  erratum: {
    corrections: [                            // 上一期说错的地方
      { wrong: '上一期写的原话', right: '正确的说法' }
    ],
    supplements: [                            // 上一期漏掉的内容
      '补一条……'
    ]
  }
}
```

3. 刷新 index.html 即可，不需要改其他任何代码。

### 字段说明

| 字段 | 必填 | 说明 |
|:--|:--|:--|
| `id` | ✅ | 唯一标识，用于记录"已投递/已读"，**不能重复** |
| `range` | ✅ | 覆盖区间。投递时刻由它推算：结束日所在那一周的周日 20:00 |
| `file` | ✅ | 相对 `index.html` 的路径 |
| `size` | | 只用于气泡里的展示 |
| `kicker` | | 气泡右上角的标签，如「第 2 期」 |
| `msg` | | 气泡正文，支持 HTML（重点用 `<span class="hl">…</span>` 高亮） |
| `errataIntro` | | 勘误区块的引导句 |
| `erratum.corrections` | | **上一期说错的**，`{wrong, right}` 成对写 |
| `erratum.supplements` | | **上一期漏掉的**，每条一句话 |

勘误区块的标题会按内容自动变化：只有补充时显示「补充同期遗漏 · N 项」，只有更正时显示「对上一期复核 · N 项更正」，两者都有就一起显示。**两项都为空时整个区块不出现。**

## 复核上一期的检查清单

- 上一期的数字有没有被后续报道更正？
- 上一期用"待发布 / 将于"表述的事件，结果出来了吗？对得上吗？
- 有没有同一周发生、但上一期漏掉的重要事件？
- 上一期标注为"未经证实"的消息，后来被证实还是被证伪了？
- 上一期标注为"源间冲突"的数字，官方最终口径出来了吗？

## 注意

- `erratum` 的内容**需要人来判断**（本质是事实核查），不是程序自动算出来的。桌宠只负责展示。
- 新增一期后，旧的那一期的 `erratum` 保持原样即可 —— 它记录的是"它当时对更上一期的复核"，是历史。
